

A Telegram-based Bingo platform that enables players to join games, receive Bingo cards, follow numbers as they are called, and claim winning combinations.

Bot

Telegram: @bigbossbingo_bot

Features

- Player registration
- Bingo game participation
- Automatic Bingo card generation
- Live number calling
- Automatic number marking and validation
- Automatic Bingo detection
- Administrative game controls
- Player management
- Game history tracking
- Wallet and prize management
- Mobile-friendly Telegram experience

Project Structure

The project will consist of the following components:

- Telegram Bot
- Backend/API
- Database
- Administrative Control Panel
- Bingo Game Engine

Security

Bot tokens, database credentials, passwords, and all other sensitive information must be stored as environment variables and must never be committed to GitHub.

Development

This project is being developed specifically for the BigBoss Bingo Telegram Bot.
